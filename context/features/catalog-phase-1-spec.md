# Dashboard UI Phase 1 Spec

## Overview

This is phase 1 of 6 for the catalog UI layout. Use the screenshot referenced below for how it should look. Use the data from the mock data file referenced below. Just import it directly for now until we implement a database.

## Requirements for phase 1

- ShadCN UI initialization and components
- show the popup edit window for each product item in the list
- ShadCN component installation
- Dashboard route at /catalog
- catalog layout and any global styles
- Dark mode by default
